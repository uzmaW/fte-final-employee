HOW TO USE
================================================================================

1. Install Dependencies:
   pip install -r requirements.txt
   pip install pytest pytest-asyncio pydantic-settings

2. Setup Environment:
   cp .env.example .env
   # Edit .env as needed

3. Run Tests:
   python3 -m pytest tests/ -v

4. View Vault:
   Open AI_Employee_Vault/ in Obsidian

5. Create Tasks:
   - Manually create files in AI_Employee_Vault/Needs_Action/
   - Use vault_manager.py API to create programmatically
   - Silver Tier will add watchers to create tasks automatically

6. Process Tasks:
   - Use vault_manager.py to read, claim, and complete tasks
   - Follow the task workflow: Needs_Action → In_Progress → Done
   - Create approval requests for high-risk actions
   - Move to Pending_Approval for user review

ARCHITECTURE NOTES
================================================================================

Local-First Design:
- All data stored in local Obsidian vault
- No cloud sync of sensitive information
- Git-friendly markdown files
- Easy to backup and version control

Modular Skills:
- Each skill is self-contained in .claude/skills/
- Can be loaded independently
- Easy to test and validate
- Reusable across different agents

Approval Gates:
- High-risk actions require human review
- Thresholds defined in Company_Handbook.md
- File-based approval (drag-drop in Obsidian)
- Audit trail of all approvals

Audit Trail:
- Every action logged to Logs/YYYY-MM-DD.json
- Supports compliance and debugging
- JSON format for easy parsing
- Never overwrites historical data

Workflow Flexibility:
- File-based state machine
- Easy to understand and debug
- Browser-friendly (Obsidian UI)
- Extensible for new task types

QUICK REFERENCE
================================================================================

Create a Task:
```python
from vault_manager import VaultManager
manager = VaultManager()
# Task files go in AI_Employee_Vault/Needs_Action/
```

Claim a Task:
```python
manager.claim_task(task_file, agent_name="claude")
# Moves to AI_Employee_Vault/In_Progress/claude/
```

Create a Plan:
```python
manager.create_plan(plan_id, title, steps, priority, related_task)
# Creates file in AI_Employee_Vault/Plans/
```

Create Approval Request:
```python
manager.create_approval_request(action_id, action_type, description, risk_level)
# Creates file in AI_Employee_Vault/Pending_Approval/
```

Complete a Task:
```python
manager.move_task_to_done(task_file, result="success")
# Moves to AI_Employee_Vault/Done/
```

Log an Event:
```python
manager.log_event(event_type, task_id, details, agent)
# Appends to AI_Employee_Vault/Logs/YYYY-MM-DD.json
```
